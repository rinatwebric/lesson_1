# nexus. — магазин компьютеров

Учебный проект: каталог, страница товара, сравнение, корзина и оформление заказа с уведомлением в Telegram.
React + Vite, светлая и тёмная темы.

## Запуск

```bash
pnpm install
cp .env.example .env.local   # впишите токен и chat id
pnpm dev                     # http://localhost:3000
```

## Данные и фото

Все товары лежат в `src/data/products.json`.

- **Каталог** (`/catalog`) показывает 12 товаров, у которых есть поле `group`
  (`gaming`, `workstations`, `laptops`, `monitors`, `peripherals`, `parts`).
- **Остальные товары** без `group` нужны конфигуратору и не показываются в каталоге.
- **Фото:** положите файл в `public/products/` и укажите `"image": "/products/имя.jpg"`.
  Лучше формат 4:3, около 1200×900. Сейчас фото вырезаны из присланных макетов.

## Конфигуратор ПК

Страница `/configurator`: выбор из 8 категорий комплектующих, проверка совместимости, готовые сборки,
количество ПК (для ПК-клубов), ссылка на сборку (состав хранится в адресе) и добавление всего комплекта в корзину.

Правила лежат в `src/configurator/rules.js`: сокет процессора и платы, тип памяти, форм-фактор платы и корпуса,
длина видеокарты, высота кулера и размер радиатора, мощность блока питания (нагрузка = процессор + видеокарта + 100 Вт,
рекомендуемый блок = нагрузка × 1.3). Данные для проверок — поле `compat` у товара в `products.json`.
Чтобы добавить новый товар в конфигуратор, заполните `compat` по примеру соседних товаров.

```bash
pnpm test   # проверка правил совместимости и готовых сборок
```

## Заказы в Telegram

1. Создайте бота у @BotFather и получите токен.
2. Напишите боту `/start`, затем откройте `https://api.telegram.org/bot<TOKEN>/getUpdates`
   и скопируйте `message.chat.id`.
3. Задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env.local` (локально)
   или в Environment Variables на Vercel.

Токен хранится только на сервере (`api/order.js`, `api/lead.js`). Сумма заказа
пересчитывается на сервере по ценам из `products.json`.

## Деплой на Vercel

1. Импортируйте репозиторий, **Root Directory** — `computer-store`.
2. Добавьте переменные окружения из шага выше.
3. Deploy. Маршруты SPA настроены в `vercel.json`.
